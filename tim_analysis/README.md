# fMRI Analysis Pipeline for TIM Task

This project provides a modular, configurable, and reproducible pipeline for conducting first-level and group-level fMRI analyses for the TIM task, built primarily around AFNI. It is designed to streamline the process, allowing researchers to easily define and execute various analysis models without modifying core scripts.

## Prerequisites

1.  **AFNI**: The core analysis software. Ensure that AFNI commands (`afni_proc.py`, `3dttest++`, `3dLMEr`, `sswarper2`, `timing_tool.py`, `@chauffeur_afni`, etc.) are available in your shell's path.
2.  **Python 3**: The pipeline's controller scripts are written in Python.
3.  **Required Python Libraries**: Install the dependencies listed in `requirements.txt`:
    ```bash
    pip install -r requirements.txt
    ```

## Directory Structure

The ecosystem is organized to separate logic, configuration, and results:

```
/tim_analysis/
├── analysis_configs/         # All pipeline configuration files.
│   ├── main_config.toml      # Global settings for paths, subjects, parameters.
│   └── analysis_models.toml  # Definitions for first-level and group GLM models.
├── logs/                     # Log files generated by each step.
├── old_scripts/              # Original monolithic shell scripts (archived).
├── scripts/                  # Modular bash scripts for each pipeline step.
│   ├── 00_create_timings.sh          # Generates AFNI .1D timing files.
│   ├── 01_preprocess_anat.sh         # Performs anatomical preprocessing (SSWarper).
│   ├── 02_preprocess_func.sh         # Performs functional preprocessing (afni_proc.py).
│   ├── 03_run_glm.sh                 # Runs GLM regression and chauffeur QC.
│   ├── 04_run_group_analysis.sh      # Runs group analyses (3dttest++ or 3dLMEr).
│   └── utils_colors.sh               # Color logging helper utility.
├── concatenate_reports.py    # Merges QC reports.
├── convert_qc_to_pdf.py      # Converts HTML QC reports to PDF.
├── era_to_timing.py          # Preprocesses Ledalab ERA data to timings.
├── export_results.py         # Exports preprocessing and GLM QC PDFs to Dropbox/output.
├── mri_file_preprocess.py    # DICOM to BIDS NIfTI converter script.
├── requirements.txt          # Python dependencies.
├── run_analysis.py           # Main Python CLI runner with concurrency.
└── README.md                 # This documentation file.
```

## Configuration

The entire pipeline is controlled by two main configuration files in `analysis_configs/`.

### Main Configuration (`analysis_configs/main_config.toml`)

Contains global paths, subject lists, sessions, and default AFNI parameters.

```toml
# Absolute path to raw BIDS data directory
input_dir = "/home/user/Documents/TIM/Pilot/Input"

# Absolute path to derivatives output directory
output_dir = "/media/user/PortableSSD/TIM/Output"

# List of subjects
[[subjects]]
id = "sub-489"
group = "TIM"
sessions = [
  { id = 1, has_scr = true }
]
```

### Analysis Model Configuration (`analysis_configs/analysis_models.toml`)

Defines parameters for each first-level GLM variation and group-level analyses.

```toml
[pain_by_rating]
description = "Pain period amplitude modulated by subjective rating."
stim_files = ["timings/pain_rating_amp.1D"]
stim_labels = ["PAIN"]
basis = "BLOCK(4,1)"
stim_types = "AM2"
requires_scr = false
glt = []

[[pain_by_rating.group_analyses]]
name = "pain_by_rating"
type = "3dttest++"
description = "One-sample t-test for pain modulated by rating."
groups = ["TIM"]
sessions = [1]
contrast = "PAIN#1_Coef"
setA_label = "PAIN"
```

## Workflow

### First-Level Analysis (`run_analysis.py`)

Manage first-level processing steps with progress bars, pretty logging, and multiprocessing.

**Steps:**
1. `create_timings`: Converts event TSVs to AFNI `.1D` timing files.
2. `preprocess_anat`: Warps T1w anatomical scans to MNI template using `sswarper2`.
3. `preprocess_func`: Runs multi-echo functional preprocessing via `afni_proc.py`.
4. `glm`: Runs GLM regression and generates `@chauffeur_afni` QC images.
5. `preprocess`: Runs `create_timings`, `preprocess_anat`, and `preprocess_func`.
6. `all`: Runs all first-level steps (`create_timings`, `preprocess_anat`, `preprocess_func`, `glm`).

**CLI Examples:**

```bash
# Process a single subject for a specific step
python run_analysis.py --subject sub-489 --step preprocess_anat

# Run all preprocessing steps for multiple subjects in parallel
python run_analysis.py --subject sub-489 sub-499 sub-500 --step preprocess --n_procs 3

# Run a specific GLM model for all subjects
python run_analysis.py --analysis pain_by_rating --step glm --n_procs 4

# Run full pipeline for all models and subjects
python run_analysis.py --step all --n_procs 8
```

### Group-Level Analysis (`run_analysis.py`)

Run group analysis using `--step group_analysis` with `--analysis <model>` and `--group_model <name>`.

```bash
# Run one-sample t-test on pain_by_rating
python run_analysis.py --step group_analysis --analysis pain_by_rating --group_model pain_by_rating

# Run anticipation by SCR group analysis
python run_analysis.py --step group_analysis --analysis anticipation_by_scr --group_model anticipation_by_scr
```
